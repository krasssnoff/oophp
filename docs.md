# OOPHP: naming rules and API map

This file fixes the direction of the public API: how methods are named, which methods have behavior of their own,
and which native functions are covered. README stays short; details live here.

## Principles

- A wrapper keeps native semantics 1:1: same arguments, same return values, same errors.
- One native function has exactly one method name. No renames, no aliases.
- Behavior of its own is allowed only in the closed list of [helpers](#helpers).

## Naming rules

A method is named after the native function it wraps.

1. **`snake_case` becomes `camelCase`**: `array_key_exists` → `Arr::keyExists`, `password_needs_rehash` → `Hash::passwordNeedsRehash`.
2. **The prefix that repeats the domain is dropped:**

   | Domain | Dropped | Example |
   | --- | --- | --- |
   | `Arr` | `array_` | `array_values` → `Arr::values` |
   | `Str` | `str_`, `str` | `str_contains` → `Str::contains`, `strtolower` → `Str::toLower` |
   | `MbStr` | `mb_`, `mb_str` | `mb_strtolower` → `MbStr::toLower`, `mb_str_split` → `MbStr::split` |
   | `Json` | `json_` | `json_encode` → `Json::encode` |
   | `Url` | `url` | `rawurlencode` → `Url::rawEncode`, `parse_url` → `Url::parse` |
   | `Regex` | `preg_` | `preg_match` → `Regex::match` |
   | `Hash` | `hash_` | `hash_hmac` → `Hash::hmac` |
   | `Stream` | `stream_` | `stream_get_contents` → `Stream::getContents` |
   | `Proc` | `proc_` | `proc_open` → `Proc::open` |

   Any other prefix stays: `fopen` → `Stream::fopen`, `file_get_contents` → `Fs::fileGetContents`,
   `preg_replace` on a string chain → `StringChain::pregReplace`.
3. **Glued words are split with capitals:** `gethostbyname` → `Net::getHostByName`, `gettype` → `Type::getType`,
   `natcasesort` → `Arr::natCaseSort`, `strtotime` → `Date::strToTime`. Not split:
   - Unix command names: `basename`, `dirname`, `mkdir`, `realpath`;
   - single-letter modifiers: `ksort`, `uasort`, `stripos` → `Str::ipos`, `fopen`, `fmod`;
   - names with digits, and `substr`: `bin2hex`, `md5`, `substr_count` → `Str::substrCount`.
4. **No renames.** Lowercased, a method name equals the native name without the domain prefix and underscores:
   `json_last_error_msg` → `Json::lastErrorMsg`, not `lastErrorMessage`. PHP method names are case-insensitive,
   so `Net::gethostbyname()` works as well.
5. **Chains mirror static names:** `Arr::replace` ↔ `ArrayChain::replace`.

`tests/ApiNamingTest.php` enforces rules 1, 2, 4, 5 and the underscore boundaries of rule 3.
Where capitals go inside glued words (rule 3) is checked in review.

## Helpers

Methods with behavior of their own: they do not map 1:1 to a native function and are exempt from the naming rule.
The list is closed. A new helper is added deliberately, in `ApiMap::HELPERS` and here.

| --- | --- |
| `Date` | `now`, `parse`, `fromTimestamp`, `create`, `createFromFormat`, `timezone`, `format`, `timestamp`, `diff`, `startOfDay`, `endOfDay`, `range` |
